# **App Name**: AgoraCare

## Core Features:

- Medication Reminders: Send voice and chat reminders for medications, tracking adherence. Uses natural language processing and tool-use to reason about different medication schedules, patient needs, and timing.
- Appointment Booking: Book appointments based on symptoms, doctor availability, and location, using smart calendar integration.
- Prescription Understanding: Explain prescriptions in natural language using OCR and AI summarization, extracting details like dosage and frequency.
- Emergency Assistance: Enable voice commands like “Call my doctor” or “Notify my son” for emergency situations.
- Multi-Profile Support: Allow switching between family members with natural prompts, enabling centralized care management.
- Calendar Synchronization: Sync with Google Calendar or Outlook to manage and display appointments.

## Style Guidelines:

- Primary color: Soft blue (#90AFC5) to evoke calmness and trust, reflecting the supportive nature of the app.
- Background color: Very light gray (#F0F4F8) to provide a clean and accessible interface.
- Accent color: Muted green (#A2D4AB) to highlight important actions and information, conveying health and well-being.
- Body and headline font: 'PT Sans' for a modern and readable feel, ensuring accessibility for all users.
- Use universal and easily recognizable icons for actions and navigation, designed with accessibility in mind.
- Employ a clean, card-based layout with ample spacing to improve readability and reduce cognitive load.
- Implement subtle animations to provide feedback on interactions and guide users through tasks.
